# SyncTogether

SyncTogether is a real-time collaborative entertainment platform
that allows users to watch videos and listen to audio together
while staying synchronized.

## Tech Stack

### Frontend

- React.js
- Vite
- Tailwind CSS
- Axios
- React Router
- Socket.IO Client

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- JWT

## Project Structure

- `client/` - Frontend application
- `server/` - Backend API and real-time server
